# CV de Yesid A. Castro R.

¡Bienvenido a mi proyecto de CV! Este proyecto es una representación digital de mi currículum vitae, desarrollado utilizando Astro, TypeScript y JSON.

## Descripción

Este proyecto muestra mi experiencia profesional, habilidades, educación, certificaciones y proyectos personales. Está diseñado para ser fácilmente accesible y mantenible, utilizando tecnologías modernas de desarrollo web.

## Características

- **Perfil Profesional**: Información básica y resumen profesional.
- **Experiencia Laboral**: Detalles sobre mis roles y responsabilidades en diferentes empresas.
- **Educación**: Información sobre mi formación académica.
- **Certificaciones**: Listado de certificaciones obtenidas.
- **Habilidades**: Conjunto de habilidades técnicas y su nivel de dominio.
- **Proyectos**: Descripción de proyectos personales y profesionales.
- **Idiomas**: Nivel de fluidez en diferentes idiomas.
- **Referencias**: Información de contacto de referencias personales y laborales.

## Tecnologías Utilizadas

- **Astro**: Framework de desarrollo web para crear sitios estáticos rápidos.
- **TypeScript**: Lenguaje de programación que añade tipos estáticos a JavaScript.
- **JSON**: Formato de datos utilizado para almacenar la información del CV.
